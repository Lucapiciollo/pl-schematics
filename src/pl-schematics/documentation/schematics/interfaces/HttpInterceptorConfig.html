Description

Configurazione dell'intercettore HTTP: timeout, nomi degli header, refresh del token e retry. Fornita tramite il token HTTP_INTERCEPTOR_CONFIG; i valori mancanti sono presi da DEFAULT_HTTP_INTERCEPTOR_CONFIG.
